# ADR 0001 — Fundação

Next.js App Router com TypeScript e Tailwind CSS 4 fornece renderização pública e estrutura para áreas privadas. Node.js 24 é a versão usada no desenvolvimento inicial. A página da PR-00 mostra apenas ofertas e uma descrição do fluxo, sem entrada de placa ou operação simulada. Fonte de sistema evita dependência de downloads de fonte durante o build. Integrações avançam em PRs revisáveis.
